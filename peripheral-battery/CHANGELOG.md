# 版本记录

## 1.2 · 2026-10-19

- 读取系统明确提供的充电状态，增加闪电和充电状态文字。
- 将系统数据读取间隔调整为 5 秒，在界面显示读取时间。
- 充电或外部供电时抑制低电量提醒。
- 接口不可用时明确显示状态未知，不根据电量上涨或 USB 连接猜测充电。
- 增加状态解析自检，包括未充电时电量上涨的情况。

## 1.1 · 2026-10-19

- 菜单栏默认采用简洁设备图标与百分比。
- 增加 SwiftUI 设置窗口、设备卡片、自定义名称与三种显示样式。
- 增加通知权限状态、测试结果和错误信息。
- 支持再次打开应用时显示设置窗口。

## 1.0 · 2026-10-19

- 读取苹果键盘和触控板电量，显示在菜单栏。
- 每分钟刷新，唤醒后刷新。
- 添加低电量提醒阈值、重复提醒抑制与登录启动入口。
