外设电量 v1.2.1 — 无需编译

系统要求：Apple Silicon（M 系列）Mac，macOS 14 或更高。
已实测：M 系列 Mac mini、macOS 26.3.1。其他系统版本尚未实测；Intel Mac 不支持此下载包。

安装
1. 把“外设电量.app”拖入访达中的“应用程序”。
2. 双击打开。若系统提示无法验证开发者，请在确认下载源为 moonwmh/mymac 后，按 Apple 官方说明，到“系统设置 → 隐私与安全性 → 仍要打开”完成首次授权。
   本版本为本地临时签名，未做 Apple 开发者 ID 签名和公证。无需关闭系统整体安全保护。
   官方说明：https://support.apple.com/zh-cn/102445
3. 在应用设置中点击“开启通知”，然后使用“测试通知”检查提醒。
4. 按需打开“登录后自动启动”。

退出之后在哪里找
访达 → 应用程序 → 外设电量。
也可以按 Command + 空格，搜索“外设电量”。
关闭设置窗口不退出程序；菜单栏的“退出外设电量”才会停止程序。

升级与迁移
先在旧版本里关闭“登录后自动启动”，再退出旧版。
将新版本放进“应用程序”，打开后重新开启登录启动。
不要同时打开两份应用，保留“应用程序”中的一份作为日常入口。

功能
每 5 秒读取系统电量；系统报告充电时显示闪电。
读取时间不等于外设上报时间，设备电量可能有延迟。
外设充电接口可能随 macOS 更新变化，无法读取时显示状态未知。

源码和使用说明：https://github.com/moonwmh/mymac/tree/main/peripheral-battery
